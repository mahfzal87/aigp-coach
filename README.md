## What changed?

AIGP Coach started as a personal study simulator. This same repository now carries its community resources, while development of the hosted platform continues separately. Existing stars, issues and commit history stay here. Earlier simulator versions remain in Git history under the terms published with those versions; this change does not revoke those permissions. Older versions are historical and should not be assumed to reflect current law, exam requirements or security maintenance.

## Corrections and contributions

Found an unclear definition or an outdated detail? Open an issue with the affected file, proposed correction and a primary-source link. Original improvements are welcome. Do not submit recalled official exam questions, paid question banks, personal information or credentials. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Content standard

AIGP Coach provides independently authored practice material, including AI-assisted questions reviewed for accuracy. Scenarios are fictional. Public sources are referenced where relevant. We do not reproduce official exam questions. AIGP Coach is not affiliated with or endorsed by IAPP.

This edition contains educational notes rather than an exam question bank. These are selective aids, not complete syllabus coverage, legal advice or a guarantee of passing. Sources last checked 2026-11-07.
