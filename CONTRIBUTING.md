# Contributing

Please open an issue before a substantial rewrite. Include the resource path, the specific ambiguity or error and a primary-source reference. Keep examples fictional and writing original.

Do not submit exam recollections, third-party question banks, credentials or user data. Check volatile facts and give a review date. Contributions should fit the personal, non-commercial study terms in LICENSE.

This repository does not accept hosted application code, payment implementations or private exam-pack exports. For product questions, visit https://aigpcoach.com/support.
